# Changelog

## 0.4.1 — repository packaging

- Moved Umn1Notch into `Tweaks/Umn1Notch/`, alongside future tweak projects.
- Added a repository workflow that builds all complete Theos projects under `Tweaks/` and publishes one shared Sileo APT index.
- Added source and package icon assets.
- Bumped the Debian package version to 0.4.1 so it can be offered as an update to 0.4.0.
- No claim is made that private API behaviour has been re-tested on-device in this repository packaging update.

## 0.4.0 — settings, media and visual effects

- Added PreferenceLoader settings page and configurable island profile.
- Added media metadata/artwork retrieval and event indicator toggles.
- Added configurable emergency confirmation gesture and decorative molten-metal hold effect.
